# Feedback form: questions to create in Google Forms

**About you**
1. Which language did you test? (Yoruba / Hausa / Igbo)
2. How well do you speak it? (Native speaker / Fluent / Some knowledge)
3. Which laptop did you use? (Mac with Apple chip / Windows / Other), and how
   much memory does it have? (8 GB / 16 GB / more / not sure)

**For each of the five tasks** (Translate, Write a message, Explain, Advise,
Summarise):

4. Which model finished its answer first? (A / B / About the same)
5. Which answer was better [language]: more natural, with correct spelling and
   tone marks? (A / B / About the same)
6. Was either answer wrong, broken or strange? If so, which, and what was
   wrong? (short text)

**Spelling**

7. Did either model leave out tone marks or special letters (for example ẹ ọ ṣ, ƙ ɗ ɓ, ị ọ ụ) where they belong? (A / B / Both / Neither)

**Overall**
8. If you could keep only one model, which would you choose? (A / B / No
   preference)
9. Why? (short text)
10. Anything else we should know? (short text)
